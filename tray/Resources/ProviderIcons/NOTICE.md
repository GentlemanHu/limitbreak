# Provider Icons — Notice

All logos in this directory are trademarks of their respective owners. They are
used here only to identify the corresponding AI provider/account in the UI and
do not imply endorsement or affiliation.

Every file is a 256x256 transparent PNG rasterized from the upstream SVG (logo
centered, ~10% padding). Rasterization steps applied to the upstream SVGs:
explicit width/height set from the viewBox, `currentColor` replaced with a fixed
color, compact SVG arc flags expanded (for CoreSVG compatibility). Files ending in
`-dark.png` are the light/white glyph variant intended for dark backgrounds; the
matching file without the suffix is the dark glyph for light backgrounds.
